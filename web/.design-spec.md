## 2. Component Library

### 2.1 `Hero` (New) — `src/features/home/Hero/index.tsx`
- **Eyebrow**: Mono font, uppercase, `tracking-[0.28em]`, brand-blue color. English only: "UNIFIED AI GATEWAY · OPENAI-COMPATIBLE ENDPOINT" with decorative thin lines on both sides (8px gap → 32px on sm+).
- **Title**: Responsive `clamp(2rem, 5.2vw, 4.5rem)` on lg+ → **strict single-line** via `lg:whitespace-nowrap`. Falls back to 1-2 lines below lg. `ll-shine-text` sweep + `ll-caret` blinking cursor (brand-blue).
- **Description**: 2-line, `max-w-2xl`, `text-base → sm:text-lg`, opacity 70-80. Model names (GPT / Claude / Gemini / DeepSeek) receive subtle emphasis: `font-medium text-[#475CFF] dark:text-[#93A1FF]` (not full bold, not colored background).
- **CTA Row**: Blue primary (`bg-[#475CFF]` + `ll-sheen` sweep, 10px downward shadow), outlined secondary. Both `rounded-xl h-11` — **must match Nav CTA's border-radius + height** (`borderRadius` is a design system constraint for CTA buttons).
- **Background**: Three `ll-drift` light blobs (top-left / top-right / bottom-center), perspective grid floor (`ll-grid-floor` rotated 68°), and `DotGrid` canvas (proximity=130, shockRadius=250, shockStrength=5) with radial mask to center focus.
- **`useTypewriter`**: Uses `performance.now()` clock, speed=42ms/char. Enabling disabled when `prefers-reduced-motion`. Title text from `t('home.banner.title')`.
- **`MacTerminalShell`** wrapper (§5) — see below.

### 2.3 `MacTerminalShell` (§5) — wrapper inside `Hero/index.tsx`
- **Outer**: `rounded-xl overflow-hidden`, vertical gradient `#1c1c1e → #161618`, 1px `rgba(255,255,255,0.08)` border, `shadow-[0_24px_60px_-12px_rgba(71,92,255,0.35)]`, inset top highlight.
- **TitleBar** (44px / `h-11`): Left — 3 macOS dots (FF5F57 red / FEBC2E yellow / 28C840 green), each with `inset 0 0 0 0.5px rgba(0,0,0,0.25)` for glassy feel. Center — `bash — 80×24` text-xs opacity 40.

## 9. 性能预算（Perf Pass 2026-11-24）

### 特效开销等级

| 特效 | 开销等级 | 渲染方式 | 降级策略 |
|------|----------|----------|----------|
| **FluideOverlay** (WebGL2 SplashCursor) | 🔴 高 | 全屏 1440×1008 WebGL2 canvas | low 档（移动/≤4核/≤4GB内存）: SIM=64/DYE=512/10 iter/4000 force；`prefers-reduced-motion` 跳过；无 WebGL2 跳过；visibility hidden + scroll 暂停 |
| **透视网格** (CSS 2D) | 🟢 低 | transform: translateX(-50%) perspective(700px) rotateX(60deg) + linear-gradient background | 仅 keyframe 改 background-position；mask-image 顶部渐隐；transform 同元素 |
| **DotGrid** (2D Canvas) | 🟡 中 | 动态 gap canvas（1440→120 / 1024→90 / 768→60 / <768→40 粒子） | 空间哈希邻 8 桶查询 O(n)；距离平方预筛；visibility + scroll 暂停；`prefers-reduced-motion` 跳过 |
| **3 光斑** (CSS 纯渐变 + blur-24px) | 🟢 低 | `radial-gradient` 预渲染 + `blur(24px)` + `will-change: transform` | 无（已从 blur-120px 降至 24px，无 runtime 高斯）；prefers-reduced-motion → `animation: none` |
| **终端打字模型循环** (React state + CSS) | 🟢 极低 | 6 个 model 名 char-by-char typed → settle 1.8s → delete → cycle | 无 |
| **标题 ll-shine-text** (CSS 纯动画) | 🟢 极低 | keyframe 改 background-position（2 层 linear-gradient 裁剪到文字） | prefers-reduced-motion → `animation: none` |

### 降级入口优先级

1. `prefers-reduced-motion: reduce` → **所有** `ll-*` 动画 + FluidOverlay + DotGrid 全部跳过
2. `WebGL2 unavailable` → FluidOverlay 跳过
3. **移动端彻底禁用**（2026-11-24 q1 pass 新增，断点 `max-width: 767px` via `useIsMobile`）
   | 特效 | 桌面端 | 移动端（< 768px） | 证据 |
   |------|--------|------------------|------|
   | **FluideOverlay** | ✅ 正常 mount | ❌ 根本不 render | `Home/index.tsx:55` 条件渲染 `{!isMobile && <FluidOverlay />}` |
   | **ll-grid-floor** | ✅ 正常渲染 | ❌ 条件跳过 | `Hero/index.tsx` JSX `{!isMobile && (<grid>)}` |
   | **DotGrid** | ✅ 正常（120-40 粒子） | ✅ 保留（gap=68px → ~40 粒子） | 本轮不卸载 |
   | **光斑** | ✅ 正常 | ✅ 正常（radial-gradient 预渲染） | 无 |
   | **终端打字** | ✅ 正常 | ✅ 正常 | 无 |
   | **useIsMobile 判定** | `window.matchMedia('(max-width: 767px)')` SSR-safe（useState undefined → useEffect 校正 false → mount 后 true 触发 re-render） |
   | **FluidOverlay useEffect 双重保险** | 同步 `window.matchMedia('(max-width: 767px)').matches` return，覆盖 SSR/hydration timing gap |
4. **设备分档**（加载时一次性）
   - 命中 mobile UA / hardwareConcurrency ≤ 4 / deviceMemory ≤ 4 → Fluid low 档 + DotGrid gap 拉大
   - 否则 → Fluid high 档
5. **生命周期暂停**
   - `document.visibilitychange → hidden` → Fluid `stop()` + DotGrid 暂停 rAF
   - `window.scroll` → Fluid `stop()` + DotGrid 暂停，250ms 无滚动后 `start()`
6. **后续计划**: §3.3 FPS 运行时自适应（需在 fluid-hero.js rAF 内部采样 frameMs）

### 网格最终参数（q1 微调 2026-11-24）

| 参数 | 之前 | 现在 | 说明 |
|------|------|------|------|
| `background-size` | `60px 60px` | **`32px 32px`** | 密度翻倍，更接近连续表面 |
| 亮色调色 `rgba(71,92,255,X)` | `0.08` | **`0.035`** | 透明度降到 44%，隐约可见 |
| 暗色调色 `rgba(71,92,255,X)` | (无) | **`0.045`** | dark 档略亮（暗色下视觉更弱） |
| `mask-image` 渐隐区间 | `0%, 70%, 80%` | **`0%, 20%, 60%`** | 远端提前消失，减少视觉重量 |
| `transform` | 仅 `rotateX(68deg)` | **同元素 `translateX(-50%) translateZ(0) perspective(700px) rotateX(60deg)`** | 透视效果正确（perspective + transform 同元素） |
| `transform-origin` | `origin-bottom` Tailwind | **`bottom center`（显式）** | 从底部向远处延伸 |
| `will-change` | 无 | **`transform`** | 独立合成层 |
| `bottom` anchor | `bottom-[-10%]` | **`bottom-0`** | 贴底，rect.bottom 正好等于 Hero bottom |

### 预算目标（真实设备）

- 桌面端（≥1440px, 独立 GPU）: 稳定 ≥ 55 FPS
- 移动端（≤390px, 无 GPU）: ≥ 30 FPS（Fluid low 档 + DotGrid 40 粒子）
- 掉帧（>32ms）下降 ≥ 50%
- 长任务（>50ms）下降 ≥ 60%
